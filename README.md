# مركز المعرفة — لوحة رصد الذكاء الاصطناعي

لوحة عربية تجمع محتوى الذكاء الاصطناعي من X، تقرأه وتحكم على قيمته، ثم تعيد كتابته
بعربية واضحة كبطاقات قابلة للبحث والفلترة.

**اللوحة المباشرة:** https://ddbb44-sudo.github.io/ai-intel-dashboard/

---

## كيف أضيف حسابًا أو أحذفه؟

كل شيء في ملف واحد: **[`accounts.json`](accounts.json)**.

اضغط على الملف ← أيقونة القلم ✏️ ← عدّل ← Commit. خلاص.

**لإضافة حساب** — أضف سطرًا داخل `accounts`:

```json
{ "handle": "AnthropicAI", "active": true }
```

`handle` وحده يكفي؛ الاسم وبقية البيانات تُملأ آليًا في أول تشغيلة.

**لإيقاف حساب مؤقتًا** — بدّل `"active": true` إلى `false`. لا يُسحب منه شيء،
وتبقى بطاقاته القديمة في اللوحة.

**لحذفه نهائيًا** — احذف العنصر كاملًا.

**لتحديد سقف يومي لحساب كثير النشر** — أضف `"max_per_day": 10`.

التغيير يسري في التشغيلة التالية. لا حاجة لتعديل أي كود.

## بنية المشروع

| | |
|---|---|
| `index.html` | الهيكل: التصميم والصور المضمّنة ومحمّل البيانات (69 KB) |
| `app.js` | المنطق: Store · Prefs · Taxonomy · FilterEngine · Ranking · UI · Router (41 KB) |
| `data/manifest.json` | فهرس الشرائح والإحصاءات — يُحدَّث كل يوم |
| `data/base-NN.json` | شرائح البطاقات، 60 بطاقة لكل شريحة |
| `data/YYYY-MM-DD.json` | شريحة يوم جديد تُضاف بالتشغيلة اليومية |
| `data/authors.json` | بيانات الحسابات |
| `data/state.json` | حالة السحب التزايدي: آخر رقم تسلسلي وآخر منشور لكل حساب |
| `accounts.json` | **الملف الذي تعدّله أنت** |

**لماذا مقسّمة؟** ليكون التحديث اليومي رفع ملف واحد صغير (~80 KB) بدل إعادة رفع
اللوحة كاملة (1.6 MB). ولأن تعديل التصميم يمسّ `index.html` وحده دون البيانات.

## قواعد ثابتة في هذا المشروع

- **لا تخمين ولا اختراع.** ما لا يتوفر يُكتب أنه غير متاح.
- **الرقم التسلسلي للبطاقة لا يتغير أبدًا** (`#000124`) — تشير إليه بأمان.
- **الضجيج يُحذف تمامًا** ولا يدخل الملف؛ يُذكر عدده في الإحصاءات فقط.
- **أي سقف يقلّص التغطية يُعلن صراحة** — لا تقليص صامت.
- المصطلحات التقنية تبقى بالإنجليزية: MCP · API · Agent · RAG · Embedding · Fine-tuning.

التفاصيل الكاملة في [`docs/00-التعليمات.md`](docs/).
